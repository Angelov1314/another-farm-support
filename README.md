# Another Farm — Support Page

Official support website for **Another Farm**, a cozy mobile farming game. Provides help documentation, FAQ, and contact information in multiple languages.

## Languages Supported

| File | Language |
|------|----------|
| `index.html` / `support.html` | English |
| `support-zh.html` | Chinese (中文) |
| `support-es.html` | Spanish (Español) |
| `support-ja.html` | Japanese (日本語) |

Privacy policy pages follow the same multilingual structure.

## Contents

- **Contact** — Direct email support link
- **FAQ** — Common questions covering save/sync, multi-device play, purchase restoration, and account deletion
- **Privacy Policy** — Available in all four languages

## Deployment

This is a static HTML site with no dependencies or build steps. Deploy to any static hosting service (GitHub Pages, Netlify, Vercel, etc.).

```bash
# Preview locally
npx serve .
```
